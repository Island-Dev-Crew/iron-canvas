# Phase 4.5: IMMERSE — Signature Depth Layer

> Run only when Phase 0/2/3.9 select IMMERSIVE. This phase inserts Agent F between FORGE and GENERATE.

## Purpose

Build the single immersive moment that makes the project feel alive: forged 3D emblem, WebGL hero, particles, shader-like atmosphere, scroll-reactive depth, cinematic load veil, or equivalent site-native signature.

This is **not** decorative 3D. It must serve the brand hierarchy and strengthen the visitor's first 15 seconds.

> **★v6 — ONE CLOCK: the world listens.** The scene never reads scroll. It subscribes to the Score
> Runtime's progress — `show.on('progress', (actId, p) => world.setAct(actId, p))` — so camera,
> colour, density and every DOM chapter play as **one continuous shot**; the signature act's `call`
> hook fires the peak. Camera = a pure function of (act, progress). Lenis only smooths native
> scroll; ScrollTrigger reads it; programmatic jumps go through `lenis.scrollTo`. A WebGL camera
> reading `window.scrollY` beside a pinned GSAP section is **Anti-Pattern #19 TWO CLOCKS**.
>
> **The listening world recedes behind quiet chapters** — it dims and slows while the visitor reads
> (background motion at most 30 % of the foreground's speed) — and returns for the signature.
> Colours come from the tokens (the RGB mirror triplets, e.g. `--accent-rgb: 224 187 110`), never
> hard-coded. Reference: `showcase/living-canvas/world.js`.

## Steps

> **★v5.2 — IMMERSE runs as a GAUNTLET LOOP.** At R3/R4 (and R2 for a signature moment),
> this phase is not build-one-and-refine — it is **fan out N world candidates → shadow each
> with a blind cross-family critic → loop until one clears the bar → ship the winner.** Steps
> 1–5 below build each candidate; step 6 is the blind-critic selection loop. Fleet width by
> register (R2 = 2 · R3 = 3 · R4 = 3–4), round cap 3, never start cold (needs the PRD + North
> Star). Full protocol: [`../references/gauntlet-loop.md`](../references/gauntlet-loop.md). This
> is why the premium tier looks the way it does — the world you ship is the survivor of a fleet.

1. **Confirm need**
   - Identify the one immersive moment and why the brand needs it.
   - If the answer is vague, downgrade to ANIMATED and document the rationale.

2. **Choose implementation surface**
   - Vanilla Three.js for static sites
   - React Three Fiber for React/Next apps
   - CSS/SVG/Canvas if true WebGL is overkill
   - Remotion/Flow/Whisk assets only when they improve the moment
   - ★v6 new Tier III worlds: prefer WebGPURenderer with TSL materials (one codebase, WGSL + GLSL;
     WebGL2 is the automatic fallback). Blender GLBs enter as budgeted assets, lazy-loaded behind
     the DOM shell. At R4 with Blender + video on, the camera rail is the **twin camera**: the WebGL
     rail reads the Blender `camera-rail.json`, so the film and the site match shot for shot.

3. **Create a control surface**
   - Central config file for material, bloom, fog, sizing, motion, density, and kill switch.
   - No magic values scattered across components.
   - ★v6 Subscribe, don't listen: wire `world.setAct(actId, p)` to the score's `progress`; no
     `scroll` listener, no `window.scrollY`, no pin of your own.
   - ★v6 Lifecycle: DPR 1.5 desktop / 1 mobile by default (2 is the ceiling); pause off-screen and on
     hidden tabs; `compileAsync` before the first frame; dispose every geometry, material, texture
     and renderer; `preserveDrawingBuffer` only under `?qa` (evidence capture); through an
     EffectComposer clear to black and tint the ground with a CSS layer (a clear colour is
     sRGB-encoded twice there — a haze).

4. **Build the degradation ladder**
   - `prefers-reduced-motion` → static final frame
   - no WebGL/context failure → static fallback
   - mobile/coarse pointer → lower density, simpler motion
   - kill switch → one-line fallback
   - ★v6 the static frame is the **composed still** — the designed final frame of the act, never
     blank; the world at rest still reads as the world

5. **Add evidence harness**
   - Playwright desktop screenshot
   - Playwright mobile screenshot
   - reduced-motion check
   - console/page error capture
   - no-horizontal-overflow assertion
   - tune/config panel check when applicable
   - ★v6 `templates/scroll-capture.spec.ts` station captures — steps the scroll, dwells, and
     screenshots every act station at 1440×900 and 390×844 (or `show.seek(actId, p)` at 0.5 and 1);
     asserts frames drawn > 0, the lit-pixel ratio, page progress → 1, zero errors, zero overflow,
     and the reduced-motion settled states
   - ★v6 Axis 7 evidence: a video of the first 5 seconds (the arrival), a 15-second slow scroll (the
     heartbeat, the recede-and-return), a reduced-motion recording (the composed still). Headless
     SwiftShader under-reports frame rate — never judge fps there; measure fps on a real GPU.

6. **Gauntlet: blind-critic selection loop** (the ★v5.2 build method)
   - Each candidate world (built via steps 1–5, isolated with `worktree-fleet`) is scored by a
     **blind critic** — a `cross-family-review` seat that scores the *artifact*, never the
     builder's self-report — against the falsifiable bar:
     - `templates/immersion-scorecard.md` average ≥ 4.0, **zero** automatic failures;
     - **North Star reference-peg screenshot diff** (the critic is visual — diff each candidate
       against the North Star, fail until they converge);
     - the pack's §5 VERIFY profile + the 7-axis audit read at the register (Axis 6 = CD3;
       ★v6 Axis 7 = Aliveness, scored from the recordings, never waived);
     - ★v6 the critic's fourth lens — a creative director: *"Does the motion serve the story, or is
       it noise?"* · *"What would make someone say 'show me that again'?"* · *"Which section feels
       leftover?"* — reading the score's director's notes.
   - **Loop:** kill losers; the surviving candidate reseeds the next round. Repeat until one
     clears every item, or the round cap (3) is hit → escalate the best-so-far + the critic's
     blocking evidence to the operator. A tie keeps the cheapest survivor.
   - **Ship the winner.** Record round count + the winner's evidence in the run ledger.
   - Then the winner must still pass Phase 7 VERIFY — gauntlet for wow, VERIFY for proof.
