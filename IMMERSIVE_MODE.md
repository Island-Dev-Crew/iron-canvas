IMMERSIVE is not a fourth speed tier. It is a **quality mode** layered on top of SWARM or MISSION when the Phase 2 Brand Personality Matrix and Phase 3/3.9 Design PRD justify frontier motion: WebGL, React Three Fiber, Three.js, particles, shader-like atmospherics, cinematic load sequences, Remotion/Flow assets, or browser-driven visual evidence.

The rule is simple: **do not call it immersive until the evidence gate passes.**

---

## When to Select IMMERSIVE

Select IMMERSIVE when at least 3 are true:

- Bold ≥ 8 or Avant-garde ≥ 8 in the Brand Personality Matrix
- The project needs one unforgettable hero/signature moment
- The visual story benefits from depth, parallax, particles, or 3D materials
- Performance tier allows progressive enhancement / WebGL fallback
- The project is flagship, launch-critical, investor-facing, or brand-defining
- There is enough time to run screenshot, console, mobile, reduced-motion, and fallback checks

Do **not** select IMMERSIVE for simple brochure pages, text-first public notices, speed-critical SEO pages, or brands whose DNA is deliberately quiet/minimal. (★v6: those still ship the aliveness floor — arrival, heartbeat, hand-feel, breath, a composed still. Quiet is not dead.)

## Acceptance Gate

IMMERSIVE passes only when:

- `templates/immersion-scorecard.md` is filled for the project
- Average score is **≥ 4.0 / 5.0**
- Automatic failures are zero:
  - No console/page errors
  - Mobile has no horizontal overflow
  - Reduced-motion path is static/clean
  - WebGL/3D has a static fallback
  - One-line kill switch exists for the immersive layer
  - Evidence screenshots exist for desktop + mobile + reduced-motion + tune/config surface when applicable
  - ★v6 No mounted-but-black canvas (frames drawn > 0 and a lit-pixel ratio above threshold at every station)
  - ★v6 Something is alive at rest (VERIFY Axis 7 — at least one animation running in view 3 s after load)
  - ★v6 Exactly one scroll owner per viewport (Anti-Pattern #19 TWO CLOCKS)
- ★v6 Station screenshots from `templates/scroll-capture.spec.ts` (every act at 1440×900 and 390×844)
  and the aliveness recordings (first 5 seconds, 15-second slow scroll, reduced motion) are attached

## Standing Doctrine

- One unforgettable immersive moment beats ten scattered effects.
- The immersive layer must amplify the site DNA, not impose Iron Canvas style.
- WebGL must be progressive enhancement, never the only usable experience.
- Motion must honor `prefers-reduced-motion`.
- ★v6 One clock: the world subscribes to the score's progress; it never reads scroll.
- ★v6 **Adjectives direct. Evidence proves.** Premium is a score, not a vibe claim. v4.3's
  "evidence beats adjectives" was right about completion claims and wrong as a writing style: the sensory words — the lens,
  the reference vibe, each act's emotion — are required *inputs* to FEEL and the score. They are
  banned only as unproven *claims*. No authority without evidence, and no evidence without intent.
