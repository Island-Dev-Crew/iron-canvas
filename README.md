- **The Voice, restored (SKILL.md §0.1).** The master blacksmith's studio, feeling first, *"a feel brief is not a mood board — it's a lens"*, *"the still elements make the moving elements land harder"*, *"whitespace is the breath between notes"* — the lines that carried the feeling, back on the main path, paired with CD3 as the conscience (§0.2).
- **The Aliveness Floor + Axis 7.** Arrival, heartbeat, hand-feel, breath and a composed still — at every register, on every surface, proven by recordings. *Restraint is not stillness.* Anti-Pattern **#18 LIFELESS** is the counterweight to #17.
- **The Score + the Score Runtime (§23).** `runtime/canvas-score.js` performs a declarative score — acts, shots, 17 verbs, 7 personalities — with reduced, static and kill-switch modes. The score is also the motion contract: motion sentence, one signature, one clock (**#19 TWO CLOCKS**).
- **Power Engines (§24).** Blender (headless clay rails with baked per-frame cameras, hero GLBs, turntables), Seedance 2.5 (fal queue or ingest), ElevenLabs sound, and a media ledger — select with a reason, re-hash, encode, promote with provenance. `runtime/camera-rail.js` plays the camera Blender baked, so the film and the site match.
- **Iron Canvas Studio (§25).** Idea in, production bible out.
- **The film surface (`surfaces/film/`).** One film score → code (HyperFrames), video (Seedance 2.5 / MiniMax) and Blender lanes; measured presets, timing and sound laws, and render gates.
- **Direction Fusion.** Voice · World · Instrument — three sources, disjoint lanes, project-owned grammar, evidence classes.
- **Taste enforced.** The design contract (3.9d) and `scripts/ic-contract.mjs`; anti-patterns **#20 FLAGGED BUT SHIPPED**, **#21 DEFAULTS AS DECISIONS**, **#22 UNREVIEWED INTERPOLATION**.
- **The erased v4.2.0 arsenal, restored.** The Creative Arsenal (~45 named motion patterns, each with a minimum tier and register), the high-end component patterns, the React / Next.js motion rules, anti-patterns Section II, responsive hardening, the tactile hand-feel rules, and the five Bento motion archetypes — lost in a 2026-06 overlay, back verbatim.
- **Structural repair.** Phase 2 content that had been spliced into Phase 3 code blocks, broken Taste-Test fences, an undefined cursor global, GSAP ease names inside CSS, inverted curve names, indigo examples acting as defaults — fixed, and guarded by `scripts/lint-skill.mjs` with a loss guard so the doctrine cannot be chopped silently again.

## Three Execution Modes

| Mode | Agents | Speed | Best For |
|------|--------|-------|----------|
| **SOLO** | 1 agent, sequential | Baseline | Quick enhancements, small sites — the aliveness floor still ships |
| **SWARM** | Orchestrator + 4 parallel Build Agents | 2-3× faster | Standard production |
| **MISSION** | Full 8-agent team | Maximum quality | Complex sites, dashboards, flagship work |
| **IMMERSIVE** | SWARM/MISSION + Agent F | Evidence-gated quality | WebGL/3D/signature motion requiring browser proof |

## The Pipeline

```
 one-line idea ─► IRON CANVAS STUDIO ─► production bible (treatment · score · engine jobs · config · mission)
 ORIENT(0) → INTERVIEW (+ the mechanism) → STUDY(1) → FEEL(2) — the Feel Brief → SCOUT(3) — Direction Fusion
 → VALIDATE(3.5) → PACKAGE(3.9) — PRD + THE SCORE + design contract + engine jobs + preflight
 → [PARALLEL BUILD AGENTS: A B C D (+ F)]  ‖  ASSET FORGE(5a) — Blender · Seedance 2.5 · sound
 → GENERATE(5) — the tournament + ledger → COMPOSE(6) → VERIFY(7) — 7 axes, Axis 7 never waived
 → HANDOFF(8) + PREMIERE — the launch film, cut from the same score
```

## Quick Start

**Read SKILL.md first.** Always. It is the single source of truth — self-contained, with the voice in its first 150 lines.

```
# FROM AN IDEA
Open studio/index.html → write the idea, the mechanism and the feel line → copy the mission into Claude Code.

# MISSION MODE — Full team
Iron Canvas v6 MISSION MODE for [project].
Full team. Discovery Interview first (Q8 = the mechanism). Phases 0-8 + PREMIERE.
Target: Awwwards Site of the Day quality — alive at rest, one signature, one clock.

# SWARM MODE — Standard production
Iron Canvas v6 SWARM MODE for [URL/project].
Phases 0-3.9 sequential (the score + preflight at 3.9). Then parallel agents ‖ ASSET FORGE. Merge and verify.

# SOLO MODE — Quick enhancement
Iron Canvas v6 SOLO for [URL].
Phase 1 FIRST — no changes before DNA profile. The aliveness floor still ships.
```

**The tools** (Node 22, zero dependencies):

```bash
node scripts/ic-preflight.mjs iron_canvas_output/                  # feel brief · score · engine config — one pass
node scripts/ic-contract.mjs --contract design-contract.json dist/  # the build keeps its design contract
node scripts/lint-skill.mjs --against <base>                       # paths · fences · voice · version · loss guard
node engines/detect.mjs                                            # which power engines are here
```
